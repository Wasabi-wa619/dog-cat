# My Workspace

自分ひとりで使うための、ローカルPCで動く業務効率化ワークスペースです。
タスク・カレンダー・メモ・表計算・ファイル管理・メールを1つの画面にまとめています。

- **インストール不要**: Python 3.9 以上の標準機能だけで動きます（追加パッケージなし）
- **データは手元だけ**: すべて `data/` フォルダ（SQLite + ファイル）に保存。クラウドには送りません
- **自分専用**: `127.0.0.1` でのみ待ち受けるため、他のPCからはアクセスできません

## 起動

| OS | 方法 |
|---|---|
| macOS / Linux | `./start.sh` |
| Windows | `start.bat` をダブルクリック |
| 共通 | `python3 -m workspace` |

ブラウザで <http://127.0.0.1:8765> が自動で開きます。終了はターミナルで `Ctrl+C`。

オプション: `--port 9000`（ポート変更）、`--data D:\backup\ws`（データ保存先の変更）、`--no-browser`

## 機能

| 画面 | できること |
|---|---|
| ホーム | 今日のタスク・期限切れ・今日/今後7日の予定・最近のメモを一覧表示 |
| タスク | 期限・優先度・プロジェクト・繰り返し（毎日/平日/毎週/毎月/毎年）。完了すると次回分を自動作成。<br>「`見積書送付 明日 #営業 !`」のように書くと期限・プロジェクト・優先度を自動で設定 |
| カレンダー | 月表示、終日/複数日の予定、期限付きタスクも表示、開始前のデスクトップ通知 |
| メモ | Markdown（見出し・リスト・チェックボックス・表・コード）、タグ、ピン留め、自動保存。<br>`- [ ]` の項目をまとめてタスクに登録 |
| シート | 簡易表計算。`=SUM(A1:A10)` などの数式、Excel からのコピー＆ペースト、CSV の取り込み（UTF-8 / Shift_JIS）と出力 |
| ファイル | アップロード（ドラッグ＆ドロップ可）・フォルダ作成・名前変更・移動・削除（ゴミ箱 `.trash` へ）。<br>「自動整理」で拡張子ごとのフォルダへ振り分け、日付を先頭に付けて命名を統一 |
| メール | IMAP で受信一覧・本文表示、SMTP で送信/返信、テンプレート（`{{name}}` `{{date}}` 差し込み）、<br>メールからワンクリックでタスク化・メモ保存 |
| 設定 | メールアカウント、ファイル整理ルール、テーマ（ライト/ダーク）、全データのバックアップ（ZIP） |

画面上部の検索欄で、タスク・予定・メモ・シート・ファイルをまとめて検索できます。

### キーボードショートカット

- `/` 検索 ・ `N` クイック追加
- `G` → `H` ホーム / `T` タスク / `C` カレンダー / `M` メモ / `S` シート / `F` ファイル / `E` メール

## メールの設定（Gmail の例）

1. Google アカウントで 2 段階認証を有効にし、「アプリ パスワード」を発行
2. 設定画面で以下を入力
   - IMAP: `imap.gmail.com` / 993
   - SMTP: `smtp.gmail.com` / 465（SSL/TLS）
   - ユーザー名: Gmail アドレス、パスワード: 発行したアプリ パスワード

パスワードは `data/workspace.db` に保存されます。PC のディスク暗号化（FileVault / BitLocker）の利用をおすすめします。

## バックアップ

設定画面の「バックアップをダウンロード」で、データベースと全ファイルを ZIP で保存できます。
`data/` フォルダをそのままコピーしても構いません（アプリを止めているときに行ってください）。

## 構成

```
workspace/
  server.py    HTTP サーバーと API（タスク・予定・メモ・シート・ファイル・メール）
  db.py        SQLite のスキーマと保存処理
  mail.py      IMAP / SMTP クライアント
  static/      画面（HTML / CSS / JavaScript、ビルド不要）
tests/         API のテスト（python3 -m unittest discover -s tests -t .）
```
