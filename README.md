# My Workspace

自分ひとりで使うための業務効率化ワークスペースです。
タスク・カレンダー・メモ・表計算・ファイル管理・メールテンプレートを1つにまとめています。

**Web 版（`web/`）** … Ubuntu・スマホ・Chromebook どこからでも使え、アカウントで同期します。

- **無料**: GitHub Pages（公開）＋ Firebase 無料プラン（ログインとデータ同期）。サーバー・クレジットカード不要
- **オフライン対応**: ネットがなくても起動・編集でき、つながったら自動で同期
- **アプリとしてインストール可能**（PWA）: ホーム画面／ランチャーにアイコンを追加できます
- **自分のデータは自分だけ**: Firestore のルールで、ログインした本人以外は読み書きできません

> `workspace/` は最初に作ったローカル PC 専用版です（後述）。今後は Web 版の利用をおすすめします。

## Web 版のセットアップ（最初の1回だけ・約15分）

### 1. GitHub Pages を有効にする

1. GitHub のこのリポジトリ → **Settings → Pages**
2. 「Build and deployment」の **Source** を **GitHub Actions** に変更
3. **Actions** タブ → 「Deploy web app to GitHub Pages」→ **Run workflow**

数分で `https://wasabi-wa619.github.io/dog-cat/` に公開されます。
この時点で「アカウントなしでこの端末だけで使う」モードは使えます。

### 2. Firebase プロジェクトを作る（同期用・無料）

1. <https://console.firebase.google.com/> に Google アカウントでログイン →「プロジェクトを作成」
   （名前は例: `my-workspace`。Google アナリティクスはオフで OK）
2. **Authentication** →「始める」→ ログイン方法で
   - **メール / パスワード** を有効化
   - （任意）**Google** を有効化
3. **Authentication → 設定 → 承認済みドメイン** に `wasabi-wa619.github.io` を追加
4. **Firestore Database** →「データベースを作成」→ ロケーション `asia-northeast1`（東京）→ **本番環境モード**
5. Firestore の **ルール** タブに、このリポジトリの [`firestore.rules`](firestore.rules) の中身を貼り付けて **公開**
6. **プロジェクトの設定（⚙）→ マイアプリ → ウェブ（`</>`）** でアプリを登録し、表示された `firebaseConfig` をコピー
7. [`web/config.js`](web/config.js) の `null` をその値に置き換えてコミット
   （GitHub の画面上で鉛筆アイコンから編集できます。この値は公開されても問題ない設定値です）

コミットすると自動で再公開されます。

### 3. アカウントを作って使い始める

1. 公開 URL を開き、メールアドレスとパスワードで **「アカウントを作成」**
2. 他の端末では同じアカウントで **ログイン** するだけで同期されます
3. 他人に登録されないよう、作成後は Firebase の
   **Authentication → 設定 → ユーザーアクション → 「作成（登録）を有効にする」をオフ** にしておくと安心です

### 端末ごとのインストール

| 端末 | 方法 |
|---|---|
| Ubuntu / Chromebook（Chrome） | アドレスバー右端の「インストール」アイコン → インストール |
| Android（Chrome） | メニュー → 「ホーム画面に追加」／「アプリをインストール」 |
| iPhone（Safari） | 共有ボタン → 「ホーム画面に追加」 |

### 無料枠の目安（Firebase Spark プラン）

保存容量 1GiB、読み取り 5 万回／日、書き込み 2 万回／日。ひとりで使う分には十分です。
ファイルは 1 つ 20MB まで（Firestore に分割して保存しています）。

## 機能

| 画面 | できること |
|---|---|
| ホーム | 今日のタスク・期限切れ・今日/今後7日の予定・最近のメモ |
| タスク | 期限・優先度・プロジェクト・繰り返し（完了すると次回分を自動作成）。<br>「`見積書送付 明日 #営業 !`」と書くと期限・プロジェクト・優先度を自動設定 |
| カレンダー | 月表示、終日/複数日の予定、期限付きタスクも表示、開始前の通知 |
| メモ | Markdown、タグ、ピン留め、自動保存、`- [ ]` の項目をまとめてタスク化 |
| シート | 簡易表計算（`=SUM(A1:A10)` などの数式、Excel からの貼り付け、CSV 入出力） |
| ファイル | アップロード、フォルダ、名前変更・移動・削除、拡張子別の「自動整理」 |
| メール | テンプレート（`{{name}}` `{{date}}`）から作成し、メールアプリ／Gmail で送信。<br>受信メールの本文を貼り付けてタスク化・メモ化 |
| 設定 | アカウント・同期状態、バックアップの書き出し／読み込み、整理ルール、テーマ |

画面右上のバッジで同期状態（✓ 同期済み ／ ⚡ オフライン ／ ↻ 同期中）がわかります。

ショートカット: `/` 検索 ・ `N` クイック追加 ・ `G` → `H`/`T`/`C`/`M`/`S`/`F`/`E` で各画面へ

### Web 版の制限

- 受信メールの一覧表示はありません（Web 版ではメールのパスワードを預からない設計のため）
- 予定の通知はアプリを開いている間のみ表示されます

## ローカル版（`workspace/`）

Ubuntu 上だけで動く最初の版です（IMAP/SMTP のメール受信・送信に対応）。

```sh
./start.sh            # http://127.0.0.1:8765 が開きます
```

**Web 版へのデータ移行**: ローカル版の「設定 → Web 版用に書き出し」でファイルを保存し、
Web 版の「設定 → 読み込み」で取り込みます（タスク・予定・メモ・シート・テンプレート・ファイルすべて）。

## 開発メモ

```
web/                 Web 版（ビルド不要の静的ファイル。GitHub Pages で公開）
  app.js             画面
  api.js             データ操作（タスク・予定・ファイル等のロジック）
  store.js           保存先（Firestore 同期 / この端末のみ IndexedDB）
  config.js          Firebase 設定
  sw.js              オフライン用 Service Worker（更新時は VERSION を上げる）
  vendor/firebase.js Firebase SDK 12.19.0 を esbuild で 1 ファイルにまとめたもの
firestore.rules      Firestore セキュリティルール
workspace/           ローカル版（Python 標準ライブラリのみ）
tests/               ローカル版のテスト（python3 -m unittest discover -s tests -t .）
```

Web 版をローカルで試す: `cd web && python3 -m http.server 8000` → <http://localhost:8000>
